# Diplomat Класс

Сайт для уроков Diplomat International School: классы 1–11, опросы по государственным предметам, игра «Итог месяца» с телефонами учеников.

- `index.html` — вход для учеников по коду игры
- `teacher.html` — кабинет учителя
- `supabase.sql` — база данных, `config.js` — подключение к ней

Как запустить — в файле ИНСТРУКЦИЯ.txt.
