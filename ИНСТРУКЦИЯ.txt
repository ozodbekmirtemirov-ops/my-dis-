DIPLOMAT КЛАСС — КАК ЗАПУСТИТЬ САЙТ
====================================

Что внутри папки
- index.html — страница для учеников (ввод кода игры). Её находят по адресу сайта и в поиске.
- teacher.html — кабинет учителя (классы, тесты, «Итог месяца», статистика). Скрыт от поиска.
- config.js — сюда вставляются два ключа от базы данных.
- supabase.sql — скрипт, который создаёт базу.
- ваши-классы.txt — ваши текущие классы (5–9 «п», «р», «с»), чтобы не вводить их заново.
- gen.js, hw1–3.js, bank5–9.js, subjects.js — готовые вопросы по 22 госпредметам для 1–11 классов.
- остальные файлы — оформление, вопросы и логика сайта, их не трогать.

Пока config.js пустой, сайт работает в «режиме проверки»: всё работает,
но только в одном браузере на одном компьютере (телефоны подключиться не смогут).


ШАГ 1. База данных (бесплатно, 10 минут)
1. Откройте supabase.com → Start your project → войдите через GitHub или почту.
2. New project: имя diplomat, пароль базы придумайте и сохраните, регион — Frankfurt (ближе всего к Ташкенту). Подождите 2 минуты.
3. Слева SQL Editor → New query → откройте файл supabase.sql в «Текстовом редакторе», скопируйте весь текст, вставьте → Run. Должно появиться «Success».
4. Слева Authentication → Sign In / Providers → Email: выключите «Confirm email» (чтобы не ждать письмо при регистрации учителя). Сохраните.
5. Слева Project Settings → API (или Data API / API Keys). Скопируйте:
   - Project URL (вида https://abcd1234.supabase.co)
   - ключ anon public (длинная строка, начинается с eyJ… или sb_publishable_…)
6. Откройте config.js в «Текстовом редакторе» и вставьте их в кавычки:
     supabaseUrl: "https://abcd1234.supabase.co",
     supabaseKey: "eyJ...."
   Сохраните файл. Ключ anon можно показывать: он открыт по замыслу, данные защищены правилами базы.

ШАГ 2. Сайт в интернете через GitHub (бесплатно, 10 минут)
1. Зарегистрируйтесь на github.com (если ещё нет аккаунта).
2. Справа вверху «+» → New repository.
   - Repository name: ВАШ-ЛОГИН.github.io  (например, mirtemirov.github.io) — тогда адрес сайта будет https://mirtemirov.github.io
     Можно и другое имя, например diplomat — тогда адрес будет https://ВАШ-ЛОГИН.github.io/diplomat/
   - Public → Create repository.
3. На странице репозитория: «uploading an existing file» → перетащите ВСЕ файлы из папки сайта (не саму папку, а её содержимое) → Commit changes.
4. Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save.
5. Через 1–2 минуты сайт откроется по адресу из пункта 2. Ученики заходят на главную страницу, учитель — на /teacher.html.
6. Чтобы обновить сайт позже: Add file → Upload files → перетащите изменённые файлы → Commit changes.
Если подключите GitHub к Claude (claude.ai → Настройки → Connectors → GitHub), я смогу сам выкладывать обновления.

Другой вариант без GitHub: app.netlify.com/drop — перетащите папку, сайт получит адрес вида https://имя.netlify.app

ШАГ 3. Первый вход учителя
1. Откройте https://ваш-адрес/teacher.html → «Новый аккаунт» → почта и пароль.
   После входа откройте Настройки → «Мои предметы» и отметьте предметы, которые вы ведёте.
   Каждый учитель школы может создать свой аккаунт и выбрать свои предметы.
2. Настройки → Резервная копия → вставьте всё содержимое файла ваши-классы.txt → «Восстановить из копии». Классы появятся.

ШАГ 4. Как проходит «Итог месяца»
1. Учитель: Итог месяца → класс, вопросы, количество и время → «Создать игру». Выведите экран на доску («Во весь экран»).
2. Ученики: открывают на телефоне адрес сайта (или сканируют QR-код с доски) → вводят код → своё имя.
3. Учитель нажимает «Начать игру». Вопрос на доске, варианты — на телефонах.
4. Очки как в Kahoot: верный ответ даёт от 500 до 1000 очков — чем быстрее, тем больше; неверный ответ или нет ответа — 0.
5. После вопроса — правильный ответ и таблица лидеров, в конце — пьедестал и средний результат класса.
   В класс сохраняется только «верно / всего» каждого участника, имена удаляются после игры.
   Пробел или Enter на клавиатуре — следующий шаг игры.

ОПРОСЫ ПО ПРЕДМЕТАМ
- 22 государственных предмета для 1–11 классов, у каждого класса 5 уровней сложности.
- Математика, алгебра, геометрия, физика, химия, информатика, английский и узбекский: по 20 вопросов на уровень,
  вопросы составляет программа, ответы проверены вычислением.
- Русский язык, литература, история, биология, естествознание, география, воспитание, право, технология,
  ИЗО, музыка, физкультура, черчение, НВП: от 4 до 6 вопросов на уровень, одинаковые для группы классов
  (например, 5–9). Их стоит дополнить своими — кнопка «Создать тест» или «Редактировать» у готового теста.

ШАГ 5. Чтобы сайт находился в Google и Safari
- Самый быстрый путь: ученики набирают адрес сайта или сканируют QR-код на доске.
- Чтобы сайт появился в поиске: search.google.com/search-console → Добавить ресурс → «Префикс URL» → адрес сайта →
  подтверждение способом «HTML-тег» (Netlify позволяет добавить тег в index.html; можно прислать тег мне — я вставлю).
  Затем «Проверка URL» → «Запросить индексирование». Обычно сайт появляется в поиске через несколько дней — 2 недели.
- Safari на iPhone ищет через Google, поэтому отдельно ничего делать не нужно.
- Собственный адрес (например, diplomat-klass.uz или .com) находится в поиске лучше; его можно купить и подключить в Netlify → Domain management.

Важно
- Бесплатный проект Supabase засыпает, если им не пользоваться 7 дней. Тогда зайдите на supabase.com и нажмите Restore.
- Удалить все результаты, оставив классы: кабинет учителя → Настройки → «Обнулить всё».
